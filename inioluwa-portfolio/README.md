# Inioluwa Olufemi — Portfolio

A responsive personal portfolio made with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — content and semantic structure
- `style.css` — layout, responsive styling, light/dark themes, project art
- `script.js` — theme toggle, mobile navigation, project filters, scroll reveals
- `assets/profile.jpg` — add your own profile photo here
- `assets/Inioluwa-Olufemi-Resume.pdf` — add your actual resume PDF here

## Run locally

1. Download or unzip the project folder.
2. Add your portrait as `assets/profile.jpg` (JPG, PNG, or WebP is fine if you also update the image path in `index.html`).
3. Add your real resume PDF at `assets/Inioluwa-Olufemi-Resume.pdf`.
4. Open `index.html` in a browser. For a better local development experience, use VS Code with the Live Server extension.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `inioluwa-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish and open the URL it provides.

All file paths are relative, so the portfolio works from a GitHub Pages project URL.

## Before publishing

- Replace the portrait placeholder by adding your own image at `assets/profile.jpg`.
- Add your real resume PDF at the expected path.
- Replace the GitHub profile links on each project card with the exact repository URL for that project.
- Confirm each demo URL is public and working.
- Check the training, education, and project descriptions for accuracy.
- The contact action opens the visitor's email application. It does not send mail from the website itself.
- Google Fonts are loaded online; if a visitor is offline, fallback fonts are used.
